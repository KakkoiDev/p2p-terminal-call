p2p-terminal-call

A text, audio and video call between two terminals. Video is drawn with half blocks in 24-bit colour, audio plays through ffplay, chat is a line at the bottom. Proof of concept.

Two terminals in one tmux window, each showing the other's video (ffmpeg test sources here, not a camera) and the shared chat.

How it works

  • Video: camera, ffmpeg, raw rgb24 frames (80x48 pixels, 10 fps), drawn as ▀ cells.
  • Audio: microphone, ffmpeg, 16 kHz mono PCM in 40 ms chunks, played with ffplay.
  • Transport: both sides connect to one small relay, the hub, built on p2p-core's server transport.

Needs

  • Node 22+, and ffmpeg with ffplay (brew install ffmpeg).
  • macOS for camera and microphone. Test sources work anywhere ffmpeg runs.
  • A truecolor terminal: Ghostty, kitty, WezTerm, iTerm2.
  • Headphones. There is no echo cancellation.

Install

npm install -g github:KakkoiDev/p2p-terminal-call

This gives p2p-call and p2p-call-hub. Or run without installing:

npx -y -p github:KakkoiDev/p2p-terminal-call p2p-call-hub
npx -y -p github:KakkoiDev/p2p-terminal-call p2p-call --server http://HUB:8787

Try it on one machine

p2p-call-hub --host 127.0.0.1                                                # terminal 1
p2p-call --name alice --video lavfi:mandelbrot --audio test --audio-out off  # terminal 2
p2p-call --name bob --video test --audio off --audio-out off                 # terminal 3

Call a friend

  1. Be on the same LAN or the same Tailscale tailnet.
  2. One of you runs the hub on your tailnet IP (tailscale ip -4): 
    p2p-call-hub --host 100.64.1.13
  3. Send your friend the address and a room name: http://100.64.1.13:8787, room ours.
  4. You: 
    p2p-call --server http://100.64.1.13:8787 --room ours --name alice
  5. Your friend: 
    p2p-call --server http://100.64.1.13:8787 --room ours --name bob

The hub relays every message unencrypted: whoever runs it can read the chat and see and hear the call, and anyone who reaches it and knows the room name can join that room. Run your own hub on a network you trust. Do not expose it to the internet.

Limits

  • No codec, no jitter buffer, no lip sync. Fine on a LAN or Tailscale, poor on a lossy link.
  • Two people per room. About 155 KB/s of video on the wire.
  • Not yet tested with a real camera and microphone or across two machines.
